## 🗺️ 2. Гарантированная видимость точек для всех пользователей
- [x] **Точки видны всем гражданам без исключения**:
  - Загрузка точек доступна публично (`optionalAuth` в `GET /api/outages`).
  - При запуске базы данных MongoDB автоматически заполняется начальными точками по районам Ташкента (Юнусабад, Чиланзар, Мирзо-Улугбек, Шайхантахур, Яккасарай, Сергели).
  - Даже при временном отсутствии соединения с бэкендом фронтенд загружает проверенные точки из локального хранилища и `INITIAL_INCIDENTS`, поэтому карта никогда не бывает пустой.
  - Добавлен фоновый опрос (polling) каждые 8 секунд: новые точки и изменения статусов мгновенно появляются на экранах всех пользователей без перезагрузки страницы.
  - Подтверждение аварии («+1 У меня тоже нет») доступно любому жителю в один клик без обязательного входа.
